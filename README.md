# Gradebook Analyzer
Author:Suhani

Date:6/12/2025

## Overview 
Gradebook Analyzer is a Python program that allows you to manage student marks, calculate statistics, assign grades, and display results in a clear tabular format. It supports both manual input and CSV file input.

## Features 
Enter student marks manually or load from a CSV file (marks.csv)

Calculate average, median, highest, and lowest marks

Assign letter grades (A, B, C, D, F) for each student

List passed and failed students

Display a final results table with student names, marks, and grades

## Usage 
1.Run the program:

gradebook_analyzer.py

2.Choose data input method:

(1 → Enter student marks manually, 2 → Load marks from a CSV file (marks.csv), 3 → Exit the program)

  1 →displays results after input
  
  2 →displays results after loading
  
  3 →no results displayed

You can view each student’s marks,their letter grade, the lists of passed and failed students, and the final results table.
